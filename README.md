# ME315 – Manipulação de Banco de Dados

Repositório contendo os desafios e o projeto final desenvolvidos na disciplina **ME315 – Manipulação de Banco de Dados**, da Universidade Estadual de Campinas (UNICAMP).

Link para o github pages: https://juliafolgueral.github.io/

## Objetivos

A disciplina teve como foco o desenvolvimento de habilidades para obtenção, organização, manipulação e visualização de dados utilizando diferentes ferramentas computacionais.

Entre os principais tópicos estudados estão:

- importação de dados em diferentes formatos;
- manipulação e transformação de dados;
- organização e limpeza de bases de dados;
- visualização de dados;
- utilização de estruturas de controle e funções;
- desenvolvimento de análises utilizando R, Python e Julia.

## Conteúdo do repositório

O repositório reúne atividades desenvolvidas ao longo da disciplina, incluindo:

- desafios práticos;
